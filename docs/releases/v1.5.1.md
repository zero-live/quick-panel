# Quick Panel 1.5.1

**常用入口，就在鼠标旁。**

Quick Panel 是一款 macOS 快捷启动面板：鼠标中键呼出，快速打开应用和网站，上层放常用入口，下层展示为当前应用配置的专属入口。

## 本次更新

- 更新检查、安装包下载及所有公开文档链接迁移到 GitHub Releases，解决外部用户无法访问原私有发布源的问题。
- 替换为石墨黑与暖白的极简双层面板图标。
- 保留液态玻璃、分页与拖拽整理、屏幕尺寸自动适配等功能。
- 补全应用内 1.5.0 与 1.5.1 更新记录。

## 下载与安装

- **版本**：1.5.1（Build 14）。
- **系统要求**：macOS 26.2 或更新。
- **架构**：Universal，包含 Apple Silicon（arm64）和 Intel（x86_64）。
- 下载附件 `Quick Panel-v1.5.1-universal.dmg`，打开后将 `Quick Panel.app` 拖入 `Applications`。
- 首次运行后，在「系统设置 → 隐私与安全性 → 辅助功能」授权 Quick Panel，以稳定监听鼠标中键。也可在设置中启用全局快捷键。

本次安装包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名和公证。macOS 可能提示无法验证开发者，请按系统提供的应用打开流程处理；发布页同时提供 SHA-256 校验文件。

**旧版本用户请从本页手动安装 1.5.1。** 旧安装包的更新地址仍指向原私有发布源，无法通过那个地址获取本次迁移；1.5.1 起使用 GitHub 检查更新。

## 校验

下载 DMG 和 `SHA256SUMS.txt` 到同一个目录，执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
