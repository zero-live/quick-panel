- [x] 创建 GitHub 公开仓库：`zero-live/quick-panel`，文档中的源码链接已指向该仓库。
- [x] 同步文档与社媒中的源码链接；安装包和更新服务当前仍指向 Gitee。
- [ ] 确认 Release 附件确实存在，系统要求与安装包匹配。文案不承诺已签名或已公证。
- [ ] 检查旧版配置升级、辅助功能授权、中键呼出、快捷键、上下层分页和跨屏适配。
- [ ] 确认打包后的 App 使用新图标；旧安装包未经重新构建，仍会使用旧图标。
- [ ] 发布新包时更新版本与构建号，按 [release.md](release.md) 更新记录、打包和验证。
- [ ] 检查待提交文件与历史提交，移除不适合公开的密钥、个人配置、日志或私人截图。
- [ ] 确认图标与仓库内容的权利归属；许可证署名当前使用 Benxin。
- [ ] 宣传图标为界面示意；如需实际界面展示，补充无私人内容的真实截图。

GitHub 仓库用于发布源码及历史版本标签。安装包仍由 Gitee Releases 提供；社媒文案与配图保存在仓库中，尚未发布到社媒。
